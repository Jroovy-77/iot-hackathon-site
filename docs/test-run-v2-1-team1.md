- สถาปนิกเขียนสัญญาข้อมูลใหม่ (ถามข้อมูลจากตัวรับทุก 2 วินาทีผ่าน Wi-Fi ในพื้นที่) และผังต่อสายรุ่นชาวบ้าน (93 เส้น) พร้อมปรับหน้ารวมลิงก์เป็นรุ่น 2
- ผู้สร้างเขียน `dashboard/` ใหม่ทั้งหมด: แผนที่ชุมชนจำลอง 14 บ้าน, หน้าผู้ส่งคำเตือน, รายการบ้านที่ยังเงียบ, คิวขอความช่วยเหลือ (บ้านละ 1 รายการ), แผงกล่องบ้าน, เดโม 60 วินาที, หน้าที่มาตัวเลข
- ผู้ตรวจตรวจ 2 รอบ ข้อ "ต้องแก้" 2 ข้อถูกแก้และยืนยันแล้ว

## เรื่องที่ผู้ใช้ต้องตัดสิน (จากสถาปนิก)
1. เสาอากาศ: Wio-SX1262 ใช้ช่อง IPEX ขา ANT ไม่ได้ต่อ → แถว "บัดกรีลวดที่ ANT" ใน parts.md ใช้ไม่ได้ ต้องใช้สายแปลง/เสา IPEX
2. ขาไม่พอ: ต้องใช้ขา RF_SW เพิ่ม ใช้ครบ 13 ขา ปุ่มสองปุ่มต้องใช้ขาร่วมกันผ่านตัวต้านทาน
3. อายุถ่าน: ลำโพงกับวงไฟไม่มีสวิตช์ตัดไฟ กินราว 14–24 mA ตอนว่าง → ถ่าน AA อยู่ราว 2–6 วัน (ประมาณการ) สั้นกว่ากรณี "ไม่มีใครมา 3–4 วัน"
4. ตัวรับ (gateway) ยังไม่มีในรายการ parts.md · ต้องตัดสินพฤติกรรม: ไม่พูดระดับน้ำในคำเตือน, กดเขียวนอกช่วงเตือน, ไม่มีปุ่มยกเลิกคำขอ
5. ความเสี่ยงอื่น: สัญญาณไฟ WS2812B เฉียดเกณฑ์, ต้องตัดปลายสาย USB ใส่ไดโอด, ยังไม่พบกฎไทยเรื่องความถี่ส่ง
