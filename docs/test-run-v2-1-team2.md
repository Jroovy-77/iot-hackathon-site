## เรื่องที่ผู้ใช้ต้องตัดสิน
1. **ยอดรวมกล่อง:** ที่ผู้ใช้ประมาณ ≈ 640 บาท แต่ผมคิดตามจริง ≈ 657 (passives ~35 แทน ~5) ผลรวมรายชิ้นบนเว็บ ≈ 664 (นับกล่อง 68) · หน้าเว็บใช้ "≈ 657 (ประมาณการ)" — **แนะนำ:** ใช้ 657 เพราะมีที่มา
2. **ตัวดึงขึ้นในชิป:** ESP-IDF ยืนยันว่าใช้ได้ตอนหลับลึกบน GPIO0–5 แต่แนะนำตัวนอก และ GPIO2 (ปุ่มเขียว) เป็นขาที่มีผลตอนบูต — **แนะนำ:** ลองจริง ถ้าบูตผิดให้คืน R2 · เกณฑ์แรงดันสายวัดน้ำใน wiring.md ยังคิดด้วย 100 kΩ เดิม ต้องคำนวณใหม่
3. **ลำโพง:** โมเดลวางที่ผนังขวา แต่ parts.md เขียนว่ารูเสียงอยู่ที่ฝา — แก้เอกสารหรือย้ายโมเดล
4. **ช่องว่างปุ่มเขียวกับวงไฟ** จริงเหลือ ~5–7 มม. ไม่ใช่ "10+" ใน parts.md (ใต้ปุ่มแดงสูงเหลือแค่ ~5 มม.)
5. ตัวต้านทาน/ตัวเก็บประจุ: ยังไม่ได้เช็กว่าชุดตัวต้านทาน 600 ตัวของ Cybertice (60 บาท) มีค่าครบ และ 10 nF หมดสต็อกหน้าร้าน
6. ฉาก 8 มีคำว่า "จำลอง" มากกว่าหนึ่งที่ (design-direction ให้ที่เดียว)
