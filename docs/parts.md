# รายการชิ้นส่วน: ปุ่มเรียกเรือ รุ่น 2 — "รุ่นชาวบ้าน"

แหล่งความจริงเดียวของทั้งสองทีม **ทุกชิ้นในโมเดล 3D และผังต่อสายต้องมาจากตารางนี้** ผู้ใช้ขอให้โมเดล "เหมือนของจริง" → ทำตามคอลัมน์ "หน้าตาจริง"

- รายการ ราคา และร้านมาจากผู้ใช้ (22 ต.ค.) · **ขนาดเป็นค่าประมาณจากสเปกทั่วไป ยังไม่ได้วัดของจริง** · ราคาเช็กร้านจริงก่อนใส่สไลด์
- **ราคาซื้อจริงล่าสุด (26 ต.ค.) — ชุด Prototype บน Breadboard: จ่ายรวม ≈ 1,625 บาท = กล่องบ้าน ≈ 804 + ตัวรับ ≈ 435 + เครื่องมือบัดกรี ≈ 386** (ดูหัวข้อ "การซื้อจริง 26 ต.ค.") · ราคาเดิมจากผู้ใช้ 23 ต.ค. (รุ่นชาวบ้าน Wio-SX1262): กล่องบ้าน ≈ 627–657 บาท · ตัวรับ ≈ 505 บาท + พาวเวอร์แบงก์
- **วิทยุ:** "Prototype ใช้ SX1276 เพราะซื้อในไทยได้ทันที ส่วนรุ่นชาวบ้านใช้ SX1262" (ถ้อยคำผู้ใช้) สองรุ่นคุยกันข้ามรุ่นได้ · **โมเดล 3D และผังต่อสายแสดงรุ่นชาวบ้าน (Wio-SX1262)**

## คำตัดสินของผู้ใช้ (22–23 ต.ค.)
1. กล่องใหญ่ขึ้นเป็น **~6×6 นิ้ว** (4×4 นิ้ว ≈ 114×114×64 มม. ใส่ปุ่ม 60 + 46 + แผ่นไข่ปลา + ถ่าน + ลำโพงไม่พอ)
2. ไฟ WS2812B 8 ดวง **ตัดทีละดวง ต่อสายเว้นระยะเป็นวงรอบปุ่มแดง** (ถ้าดัดทั้งเส้น 8 ดวงจะได้วงแค่ ~42 มม. เล็กกว่าปุ่ม 60 มม.)
3. ไฟเลี้ยง: **หัวชาร์จ USB-C จากไฟบ้านเป็นหลัก + ถ่าน AA 3 ก้อนสำรองตอนไฟดับ**
4. เรื่องการฟัง (ผู้ใช้แก้ข้อมูลของแชท): SX1276 ก็ให้สมองหลับแล้วรอฟังได้ ชิปวิทยุปลุกสมองเมื่อมีข้อความเข้า ความต่างคือไฟ — ตอนฟัง SX1276 ≈ 10.3 mA, SX1262 ≈ 4.6 mA และ SX1262 สลับเปิด-ปิดการฟังเป็นช่วง ๆ ได้เองโดยไม่ต้องปลุกสมอง ถ่านจึงอยู่ได้นานกว่ามาก (ตัวเลขไฟจาก datasheet ที่ผู้ใช้ให้มา — ใช้ในเอกสาร/ผังต่อสายได้ ถ้าขึ้นเว็บให้ระบุว่า "จาก datasheet")
6. (23 ต.ค.) **เพิ่มสวิตช์ตัดไฟ P-MOSFET** · ข้อกำหนด: **ตอนไฟดับ ถ่าน AA ต้องอยู่ได้ ≥ 7 วัน (ค่าออกแบบ วัดจริงหลังทดสอบ)** ยาวกว่ากรณี "ไม่มีใครมา 3–4 วัน"
7. (23 ต.ค.) ลำดับคืนขาบอร์ดที่ผู้ใช้กำหนด: (ก) เช็กว่าสวิตช์สลับเสาของ Wio-SX1262 คุมด้วยขา DIO2 ของชิปได้ไหม (RadioLib `setDio2AsRfSwitch`) ถ้าได้ไม่ต้องใช้ขาบอร์ด (ข) สายวัดน้ำใช้ขาร่วมกับ**ปุ่มแดง** (ห้ามร่วมกับปุ่มเขียว — น้ำแตะสายจะกลายเป็น "ปลอดภัย ยกเลิกคำขอ") เฟิร์มแวร์แยก: ปิดค้างเกิน 30 วิ = น้ำขึ้น / กดแล้วปล่อยในไม่กี่วิ = คนกด (ค่าออกแบบ) (ค) เปลี่ยน LED 1W เป็น WS2812 ดวงที่ 9 หันออกนอกกล่อง ใช้สายข้อมูลเส้นเดิม (ถูกลง 8 บาท ต้องลองว่ากลางคืนสว่างพอให้เรือเห็นไหม) · ตัดการวัดถ่านเป็นทางสุดท้าย
8. (23 ต.ค.) ปุ่มเขียว: **กดสั้น = ฟังข้อความล่าสุดซ้ำ** (แบบเครื่องรับข่าวภัยญี่ปุ่น) · **กดค้าง 2 วิ = ปลอดภัย ยกเลิกคำขอของบ้านตัวเอง**
9. (24 ต.ค.) **ลำโพงติดผนังขวาด้านใน รูเสียงเจาะที่ผนังขวา ไม่ใช่ฝา** (ตรงกับเว็บ 3D และหน้า `wiring/`)
5. Wio-SX1262 เป็นชิปติดผิวแผ่นวงจร เสียบ breadboard ไม่ได้ → เหมาะกับรุ่นชาวบ้านที่ใช้ PCB ไข่ปลาหรือแผ่นวงจรสั่งทำ

## ผังต่อสาย
- **`docs/wiring.md` (dash-architect เขียน) เป็นแหล่งความจริงของการต่อสาย** ทีม 2 วาดฉาก Wiring Diagram จากไฟล์นั้นเท่านั้น
- ข้อจำกัดที่ต้องเช็กกับ datasheet ก่อนเลือกขา (แชทรวบรวมไว้ ยังไม่ได้ยืนยันทุกข้อ):
  - ESP32-C3 ปลุกจากหลับลึกได้เฉพาะขากลุ่ม RTC (GPIO0–5) → ปุ่มแดง ปุ่มเขียว และขา IRQ ของวิทยุ (DIO1) ควรอยู่กลุ่มนี้
  - ขา strapping GPIO2 / 8 / 9 มีผลตอนบูต ระวังต่อปุ่มหรือของที่ดึงขาลงตอนเปิดเครื่อง · Super Mini มี LED บนบอร์ดที่ GPIO8
  - Super Mini ใช้ขาได้ราว 13 ขา (GPIO0–10, 20, 21) — วิทยุ SX1262 ใช้ **6 ขา** SCK/MOSI/MISO/NSS/BUSY/DIO1 (RF_SW ต่อ 3V3, NRST ใช้ตัวดึงขึ้น ไม่ใช้ขาบอร์ด) สายวัดน้ำใช้ 1 ขา (ต่อขากลุ่มปลุกได้ ถ้าอยากให้น้ำถึงเกณฑ์แล้วปลุกกล่องทันที) ต้องจัดให้ลงตัว
  - ESP32-C3 ไม่มีวงจรแปลงเสียง (DAC) → ส่งเสียงด้วย PWM ผ่านตัวกรอง RC เข้า PAM8403
  - WS2812B ใช้ไฟจากรางไฟ ~4.2–4.7V สัญญาณข้อมูล 3.3V มีตัวต้านทานอนุกรม · LED 1W ต้องมีตัวจำกัดกระแส
  - สายวัดน้ำ: จ่ายไฟให้สายเฉพาะตอนอ่านค่าแล้วปิด (กันขั้วทองแดงกร่อนจากไฟฟ้า) + ตัวต้านทานดึงขา
  - ไฟบ้าน + ถ่าน: ต้องกันไฟไหลย้อนทั้งสองทาง (ไม่ให้หัวชาร์จดันไฟเข้าถ่าน AA และไม่ให้ถ่านไหลกลับเข้าหัวชาร์จตอนไฟดับ)

1. pcb ยึดก้นกล่อง (mcu, radio, amp, diodes, passives, q-drive, q-power บัดกรีอยู่บนแผ่น) → 2. battery ข้างแผ่นไข่ปลา → 3. speaker ผนังขวาด้านในฝั่งรูเสียง → 4. led ดวงที่ 9 ผนังข้าง หันออก → 5. antenna เสายางเสียบช่อง IPEX วางตามขอบด้านบนในกล่อง → 6. power-in (+ water-probe ถ้าเป็นบ้านติดเตียง) ผ่านซีลด้านล่าง → 7. box-body → 8. leds 8 ดวงเป็นวงรอบรูปุ่มแดงใต้ฝา → 9. btn-sos และ btn-ack ทะลุฝา → 10. box-lid

## ข้อสงสัยทางวิศวกรรม (ให้ผู้ใช้ตัดสิน — ทีมห้ามแก้รายการเอง)
1. **สายวัดน้ำเตือนผิด:** ความชื้น ไอน้ำ หรือแมลง/หยดน้ำเกาะระหว่างปลายสายอาจทำให้กล่องคิดว่าน้ำถึงแล้ว → อ่านค่าซ้ำหลายครั้งก่อนตัดสิน + มีเงื่อนไข "ไม่ตอบ 2 ชม." และ อสม. ยืนยันอยู่แล้ว
2. **ปลายสายกร่อน/มีคราบ** ถ้าแขวนทั้งฤดู ค่าอาจเพี้ยน → ทดสอบกับน้ำท่วมจริง (น้ำขุ่น น้ำเค็ม) และเช็กก่อนฤดูน้ำ
3. **ถ่าน AA ใกล้หมด** (3 × 1.1V ≈ 3.3V หักไดโอด ~0.3V) ตัวลดไฟของ Super Mini อาจจ่าย 3.3V ไม่พอ → ควรมีการแจ้งเตือน "ถ่านอ่อน" ก่อนถึงจุดนั้น
4. **LED เปิดเครื่องบนบอร์ด Super Mini** กินไฟตลอดเวลา ถ้าใช้ถ่านต้องถอดออก
5. **"เสียงดังสุด" จาก PAM8403 + ลำโพง 3W ที่ไฟ ~4.5V** ต้องลองว่าผู้สูงอายุได้ยินจากห้องอื่นไหม
6. **WS2812B ที่ ~4.5V:** ส้มกับเหลืองต้องดูออกว่าต่างกัน ต้องลองของจริง
7. **การฟังคำเตือนทั้งฤดู:** คำเตือนต้องส่งซ้ำนานพอให้กล่องที่ฟังเป็นช่วง ๆ ได้ยิน — data contract ต้องคิดเวลาส่งซ้ำ
