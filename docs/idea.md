# ไอเดีย: ปุ่มเรียกเรือ (รุ่น 2 — กล่องคุยสองทาง)

> ที่มา: ผู้ใช้ส่งมาเมื่อ 22 ต.ค. 2569 (ไอเดียที่ล็อกแล้ว) แทนรุ่น 1 ที่เก็บไว้ใน `_archive/boat-button-v1/`
> หัวข้อ "กติกาตัวเลขและแหล่งที่มา" และ "ต้นฉบับจากผู้ใช้" ห้ามแก้ความหมาย

## สรุปสั้น (อ่านอันนี้ก่อน)
- **หนึ่งประโยค:** กล่องติดบ้านที่คุยกับทีมช่วยเหลือได้สองทาง ก่อนน้ำมาถามว่า "ได้ยินไหม" พอน้ำมาแล้วก็ตอบว่า "ได้ยินแล้ว กำลังไป"
- **ผู้ใช้:** ผู้สูงอายุ/ผู้ติดเตียงในพื้นที่น้ำท่วม ไม่มีสมาร์ตโฟน · ช่วง (ก) 12–48 ชม. ก่อนน้ำเข้าบ้าน (ข) ตอนติดอยู่ ไฟดับ เสามือถือล่ม
- **ใหม่จากรุ่น 1:** เพิ่ม "ขาเตือน" (ก่อนน้ำมา) + รายการ "บ้านที่ยังเงียบ" + "ขอแทนอัตโนมัติ" สำหรับบ้านติดเตียง
- **3 หน้าที่ของกล่อง:**
  1. เตือน → ไฟส้มกะพริบ + เสียง → กดเขียว = ได้ยินแล้ว (ไฟเขียว) → ไม่กดใน 6 ชม. = "บ้านเงียบ" ให้ อสม. ไปเคาะ
  2. ขอช่วย → กดแดงค้าง 2 วิ (ไฟแดง) → ทีมกด "รับเรื่อง" (ไฟเหลือง + เสียง "ทีมรับเรื่องแล้ว กำลังมา") → ช่วยเสร็จ (ไฟเขียว)
  3. ขอแทน → บ้านติดเตียง น้ำ ≥ 50 ซม. เหนือพื้น + ไม่ตอบ 2 ชม. → กล่องขอเอง ขึ้นลำดับแรก (อสม. ยืนยันก่อนส่งเรือ)
- **สีไฟมีความหมายเดียว (ทุกหน้าเว็บต้องใช้ตรงกัน):** ส้ม = เตือน รอคนตอบ · เขียว = ได้ยินแล้ว / ช่วยเสร็จ · แดง = ขอความช่วยเหลือ · เหลือง = ทีมรับเรื่องแล้ว
- **1 บ้าน = 1 ID = 1 คำขอที่เปิดอยู่** (คำขอซ้ำ = 0)
- **ปุ่มเขียว (23 ต.ค.):** กดสั้น = ฟังข้อความล่าสุดซ้ำ · กดค้าง 2 วิ = ปลอดภัย ยกเลิกคำขอของบ้านตัวเอง (บ้านติดเตียง: แดชบอร์ดไม่ลบ ขึ้น "ยกเลิกโดยบ้าน ควรโทรยืนยัน")
- **ขาดการติดต่อ (23 ต.ค.):** กล่องส่ง "ยังอยู่" ทุก 6 ชม. (ค่าออกแบบ) เงียบเกินกำหนด = "ขาดการติดต่อ" ขึ้นบนสุดของรายการเหมือนบ้านเงียบ · "ส่งไม่ถึง" มีได้แค่ที่กล่อง (ตัวรับไม่รู้ว่ามีการส่ง)
- **ถ่าน:** ตอนไฟดับต้องอยู่ได้ ≥ 7 วัน (ค่าออกแบบ วัดจริงหลังทดสอบ)
- **PoC ไม่มีอุปกรณ์จริง:** แดชบอร์ดใช้โหมดจำลองเป็นหลัก · ฉากสุดท้ายเว็บ 3D ลองใช้กล่องเสมือนได้ (หมุน กด เห็นไฟ/ผลลัพธ์ มีเสียง) ติดป้าย "จำลอง"
- **เว็บ:** แดชบอร์ดต้องใช้ได้โดยไม่มีเน็ต (เปิดจาก Wi-Fi ของตัวรับ) · ตัวเลขที่ออกแบบเองติดป้าย "ค่าออกแบบ จะปรับหลังทดสอบ" · ผลทดสอบทั้งหมด "รอผลทดสอบ 25 ต.ค."
- **ทิศทางหน้าตา:** แบบ ก "แบบแปลนวิศวกร" — ดู `docs/design-direction.md`
- **อุปกรณ์:** "รุ่นชาวบ้าน" ≈ 657 บาท/กล่อง (ESP32-C3 Super Mini + Wio-SX1262 ในกล่อง 6×6 นิ้ว ไฟบ้าน + AA สำรอง) — รายการเต็มใน `docs/parts.md` · ผังต่อสายใน `docs/wiring.md`

## สถาปัตยกรรมที่ผู้ใช้กำหนด (ฐานของ data contract)
- **กล่องบ้าน (รุ่นชาวบ้าน — อัปเดต 22 ต.ค. แทนรายการในต้นฉบับ)** ESP32-C3 Super Mini + Wio-SX1262 (Prototype ใช้ SX1276) ย่าน AS923 920–925 MHz · ปุ่มแดง 60 มม. + ปุ่ม 46 มม. "ได้ยินแล้ว / ปลอดภัย" · WS2812B 8 ดวงเป็นวงรอบปุ่มแดง · เสียงไทยเก็บใน ESP32 → PAM8403 + ลำโพง 3W · LED 1W กะพริบหน้าบ้าน · ไฟบ้าน USB-C + AA 3 ก้อนสำรอง · กล่องกันน้ำ 6×6 นิ้ว (Leetech 68 บาท) · สายวัดน้ำ 2 เส้นแขวนที่ระดับเกณฑ์ (0 บาท) เฉพาะบ้านติดเตียง — **ไม่ใช้ JSN-SR04T แล้ว**
- **ตัวรับ (gateway)** ESP32-C3 + Wio-SX1262 + เสา 3dBi บนตึกสูงหรือเรือ ไม่ต้องใช้เน็ต · **PoC (23 ต.ค.): ส่งข้อมูลทางสาย USB เข้าโน้ตบุ๊กที่เปิดแดชบอร์ด** · แผนพัฒนา: ตัวรับปล่อย Wi-Fi + หน้าเว็บเล็กเอง
- **ทิศทางลง (ตัวรับ → กล่อง):** คำเตือน, ACK, "รับเรื่อง", "เสร็จ" · **ทิศทางขึ้น (กล่อง → ตัวรับ):** "ได้ยินแล้ว", ขอช่วย, ขอแทนอัตโนมัติ, ระดับน้ำ, แบต
- **ฟังข้อความแบบประหยัดแบต:** สมองหลับ ชิปวิทยุรอฟังแล้วปลุกสมองเมื่อมีข้อความเข้า (ทำได้ทั้ง SX1276 และ SX1262) — SX1262 กินไฟตอนฟังน้อยกว่า (≈ 4.6 vs 10.3 mA จาก datasheet) และสลับเปิด-ปิดการฟังเป็นช่วง ๆ ได้เองโดยไม่ต้องปลุกสมอง (ค่าออกแบบ)
- **ผู้ส่งคำเตือน:** อปท./ปภ. — PoC จำลองหน้าจอผู้ส่ง
- อสม. ลงทะเบียนบ้านเปราะบางล่วงหน้า (ID + พิกัด + ติดเตียงไหม)
- **ขอบเขต PoC:** กล่อง 2 + ตัวรับ 1 + แดชบอร์ด เท่านั้น — ในรอบนี้ทั้งหมดเป็น "จำลอง" เพราะไม่มีอุปกรณ์จริง

## ข้อกำหนดเว็บที่ตามมา
- **dashboard/** ห้ามโหลดอะไรจากเน็ต (ไม่มี CDN, web font ภายนอก, tile แผนที่) วาดแผนที่ชุมชนจำลองเอง (PoC เปิดบนโน้ตบุ๊กต่อตัวรับทาง USB — ไฟล์ไม่ต้องเล็กพอเก็บในชิปแล้ว แต่ยังห้ามใช้เน็ต)
- **โหมดจำลองเป็นหลัก** มี `?demo=auto` เล่นเดโม 60 วิ และ `?at=<วินาที>` กระโดดไปจุดใดก็ได้ (ใช้ถ่ายภาพ/อัดคลิป) ป้าย "จำลอง" ที่เดียวชัด ๆ
- **เดโมเร่งเวลา:** 6 ชม. / 2 ชม. ในเดโมย่อเหลือไม่กี่วินาที ต้องมีป้ายบอกว่า "เดโมเร่งเวลา"
- **exploded/** เว็บเลื่อนแยกชิ้น 3D ใช้ไลบรารีใน `exploded/vendor/` · ฉากสุดท้าย = ลองใช้กล่องเสมือนจริง
- ห้ามใช้โลโก้หน่วยงานรัฐจริง · ยายสมศรีเป็นตัวละครสมมติ → กำกับ "เรื่องสมมติ"

## เดโม 60 วินาที (ต้นฉบับผู้ใช้)
- 0–15 วิ: Cell Broadcast เข้ามือถือที่ยายไม่ได้ใช้
- 15–30 วิ: กล่องเตือน บ้านส่วนใหญ่กดเขียว แดชบอร์ดขึ้นว่า "ยังเงียบ 2 บ้าน (ติดเตียง 1)"
- 30–45 วิ: กดแดง ไฟเปลี่ยนจากแดงเป็นเหลืองพร้อมเสียง และคำขอขึ้นแผนที่แค่ 1 รายการต่อบ้าน
- 45–60 วิ: บ้านติดเตียงส่งขอความช่วยเหลือเองและขึ้นเป็นลำดับแรก

## คำพูดของกล่อง (ผู้ใช้ยืนยัน 22 ต.ค. — ใช้ตามนี้ทุกคำ)
ทุกประโยคเป็น **ค่าออกแบบ จะปรับหลังทดสอบผู้ใช้** · พูดช้า ๆ ไม่เกิน ~8 วินาที

| สถานะ | คำพูด |
|---|---|
| ส้ม — เตือน (พูดซ้ำทุก 10 นาทีจนกว่าจะกด) | "เตือนภัยน้ำท่วม น้ำจะเข้าบ้านภายในพรุ่งนี้ ยกของขึ้นที่สูง พาคนป่วยขึ้นชั้นบน ได้ยินแล้วกดปุ่มเขียว" (อัดคำว่า วันนี้ / คืนนี้ / พรุ่งนี้ ไว้ให้เจ้าหน้าที่เลือก) |
| หลังกดเขียว | "ขอบคุณ ทีมรู้แล้วว่าบ้านนี้ได้ยิน" |
| แดง — กดแดงค้าง | "ส่งขอความช่วยเหลือแล้ว รอสักครู่" |
| ส่งไม่ถึง | "ยังส่งไม่ถึง กำลังลองใหม่" |
| เหลือง — ทีมรับเรื่อง | "ทีมรับเรื่องแล้ว เรือกำลังมา อยู่บนที่สูง อย่าลงน้ำ" |
| เขียว — เสร็จ | "ทีมช่วยเหลือบ้านนี้เรียบร้อยแล้ว" |
| ขอแทนอัตโนมัติ | "น้ำเข้าบ้านแล้ว กล่องขอความช่วยเหลือให้แล้ว" |
| ถ่านอ่อน | "ถ่านใกล้หมด กรุณาเปลี่ยนถ่าน" |
| กดเขียวค้าง 2 วิ (ปลอดภัย) | "ยกเลิกคำขอแล้ว ทีมรู้ว่าบ้านนี้ปลอดภัย" |
| กดเขียวสั้น | เล่นข้อความล่าสุดซ้ำ |

- หน้าผู้ส่งคำเตือนบนแดชบอร์ดต้องให้เลือก วันนี้ / คืนนี้ / พรุ่งนี้ ได้ · ค่าออกแบบ "พูดซ้ำทุก 10 นาที" ใส่ป้ายตามกติกา
- เหตุผลของ "อย่าลงน้ำ": "Just six inches of fast-moving water can knock over and carry off an adult." — US National Weather Service https://www.weather.gov/box/flood_safety (6 นิ้ว ≈ 15 ซม.)
- **ข้อเสนอของผู้ใช้:** อัดเสียงด้วยเสียงผู้ใหญ่บ้านหรือ อสม. ตัวจริง เพราะบทเรียนจากหาดใหญ่คือชาวบ้านเชื่อผู้นำในพื้นที่มากกว่าข้อความจากรัฐ → ทดสอบวันที่ 25 (ข้อ D: เทียบเสียงคนที่รู้จักกับเสียงทั่วไป)
- เรื่องเล่ายายสมศรีในต้นฉบับยังใช้คำเดิมได้ ("ทีมรับเรื่องแล้ว กำลังมา") แต่เสียงกล่องบนเว็บใช้ตารางนี้

## ค่าออกแบบ (ใส่บนเว็บได้ ต้องกำกับ "ค่าออกแบบ จะปรับหลังทดสอบ")
กดแดงค้าง 2 วิ · ไม่ยืนยันใน 6 ชม. = บ้านเงียบ · ขออัตโนมัติเมื่อน้ำ ≥ 50 ซม. เหนือพื้น + ไม่ตอบ 2 ชม. · ฟังข้อความแบบประหยัดแบต · ราคากล่องบ้าน ≈ 657 บาท · ตัวรับ ≈ 505 บาท (ประมาณการ จากผู้ใช้ 23 ต.ค., ราคากล่องอัปเดต 23 ต.ค. รอบ 2) · ถ่าน ≥ 7 วันตอนไฟดับ · "ยังอยู่" ทุก 6 ชม. · แยกน้ำขึ้น/คนกด ที่ 30 วิ — ห้ามใช้ราคา 1,200–1,800 ของต้นฉบับเดิม

## ผลลัพธ์ที่จะวัด (แสดงเป็น "รอผลทดสอบ 25 ต.ค." ทั้งหมด)
% บ้านเปราะบางที่ยืนยันก่อนน้ำมา · เวลาจากเตือนถึงยืนยัน · % ที่อ่านความหมายไฟถูก · คำขอซ้ำ = 0 ตามการออกแบบ

## กติกาตัวเลขและแหล่งที่มา (ต้นฉบับจากผู้ใช้ — ใช้กับทุกหน้าเว็บ)
ใช้เฉพาะตัวเลขต่อไปนี้ ห้ามแต่งเพิ่ม และใส่แหล่งที่มาใต้ตัวเลขทุกตัว
- น้ำท่วมใต้ พ.ย.68 ตาย 162 คน (ศป.กฉ. 8 จังหวัด) — https://www.thaipbs.or.th/program/SouthFloods68/watch/p9wtebfhaj1l
- หลายพื้นที่การช่วยเหลือยังเข้าไปไม่ถึง — Thai PBS ข่าวค่ำ 24 พ.ย. 68 https://www.thaipbs.or.th/program/EveningNews/episodes/111779
- (29 ต.ค. 69) ลิงก์เดิม thaipbs 358938 ไม่มีเลข 162 และไม่มี "ไม่มีใครมา 3–4 วัน" · "3–4 วัน" ยังหาแหล่งไม่เจอ → ห้ามใช้จนกว่าผู้ใช้ให้ลิงก์
- Cell Broadcast ส่งหลายรอบแต่คนไม่รู้/รู้ช้า, คำขอซ้ำ, ผู้สูงอายุไม่มีมือถือหายจากแผนที่ — https://www.bangkokbiznews.com/tech/ai/1209690
- ผู้สูงอายุ 60+ ใช้เน็ต 67.3% (≈1 ใน 3 ไม่ใช้) — https://www.nso.go.th/nsoweb/storage/survey_detail/2025/20250228090924_27941.pdf
- 6 ต.ค.69 น้ำท่วม 27 จว. กระทบ 3,143,962 คน — https://www.bangkokbiznews.com/news/1255230
- วิทยุรับข่าวภัยในบ้านญี่ปุ่น เคยมีสองทางแต่ถูกเสนอตัดเพราะแพง — https://www.soumu.go.jp/main_content/000487220.pdf
- น้ำไหลเชี่ยวลึกแค่ 6 นิ้ว (≈15 ซม.) พัดผู้ใหญ่ล้มได้ — US NWS https://www.weather.gov/box/flood_safety
- **ระยะ LoRa จากงานวิจัย (เพิ่ม 23 ต.ค. ผู้ใช้ขอ "ระยะจริง") — ไม่ใช่ผลของกล่องเรา ต้องเขียน "จากงานวิจัย" ทุกครั้ง:**
  - ในเมือง เสาสูงแค่ 1.5 ม. ส่งได้ราว 1 กม. · ริมทะเลมองเห็นกัน (SF12, 20 dBm) ได้เกิน 4 กม. — Callebaut et al. 2019 (EuCNC) https://arxiv.org/abs/1909.08300
  - ไกลสุดเกิน 15 กม. บนพื้น และเกือบ 30 กม. บนผิวน้ำ (868 MHz, 14 dBm, SF สูงสุด) — Petäjäjärvi et al. 2015 (ITST) https://www.nokia.com/bell-labs/publications-and-media/publications/on-the-coverage-of-lpwans-range-evaluation-and-channel-attenuation-model-for-lora-technology/
  - ระยะของกล่องเราเอง: ยังไม่ได้วัด → "รอผลทดสอบ 25 ต.ค." (ถ้าวัดได้ใส่ค่าจริงแทน)
- FMAS (มาเลเซีย) — ห้ามเขียนว่า "FMAS ตอบกลับไม่ได้" ให้เขียนว่า "ไม่ได้บอกว่าคนขอได้อะไรกลับ" — https://www.jamesdysonaward.org/en-MY/2025/project/flood-monitoring-alert-and-sos-system-fmas-1 (ลิงก์จากรุ่น 1)

## ต้นฉบับจากผู้ใช้ (22 ต.ค. 2569 — ห้ามแก้)

ปุ่มเรียกเรือ: กล่องคุยสองทางสำหรับบ้านน้ำท่วม

1) หนึ่งประโยค
กล่องติดบ้านที่คุยกับทีมช่วยเหลือได้สองทาง ก่อนน้ำมาถามว่า "ได้ยินไหม" พอน้ำมาแล้วก็ตอบว่า "ได้ยินแล้ว กำลังไป"

2) เรื่องเล่าก่อน/หลัง (ยายสมศรีเป็นตัวละครสมมติ)
ยายสมศรีอายุ 78 กลางวันอยู่บ้านคนเดียว ไม่มีสมาร์ตโฟน

ไม่มีกล่อง: SMS เตือนน้ำเข้าเครื่องหลานที่ไปทำงาน ยายไม่รู้เรื่อง ตีสองน้ำเข้าบ้าน โทรหาใครก็ไม่ติดเพราะเสาสัญญาณล่ม ไม่มีใครรู้ว่ายายติดอยู่ในบ้าน
มีกล่อง: บ่ายวันก่อน กล่องพูดว่า "พรุ่งนี้น้ำจะเข้าบ้าน ให้ขึ้นชั้นสอง ได้ยินแล้วกดปุ่มเขียว" ยายไม่ได้ยิน เลยไม่ได้กด ชื่อยายจึงขึ้นรายการ "บ้านที่ยังเงียบ" แล้ว อสม. มาเคาะประตูก่อนน้ำมา
ถ้ายายติดอยู่ในบ้านจริงๆ ยายกดปุ่มแดง ไฟเปลี่ยนเป็นเหลือง พร้อมเสียงบอกว่า "ทีมรับเรื่องแล้ว กำลังมา" ยายรู้ว่าต้องรอ ไม่ต้องลุยน้ำออกไปเอง

3) ทำงานยังไง
เตือน: ไฟวงแหวนกะพริบสีส้ม เสียงดังสุดพูดว่าน้ำจะมาถึงแค่ไหนและต้องทำอะไร กดปุ่มเขียวแปลว่า "ได้ยินแล้ว" ไฟจะเป็นสีเขียว
ขอความช่วยเหลือ: กดปุ่มแดงค้าง 2 วินาที ไฟเป็นสีแดง พอทีมกด "รับเรื่อง" ไฟเปลี่ยนเป็นเหลืองพร้อมเสียง พอช่วยเสร็จไฟเป็นสีเขียว
กดแทนคนที่กดไม่ได้: บ้านที่ลงทะเบียนว่ามีผู้ติดเตียง ถ้าน้ำในบ้านสูงเกินเกณฑ์และไม่มีใครตอบ กล่องจะขอความช่วยเหลือเอง

4) ทำไมเชื่อว่าได้ผล
ปัญหาคือการสื่อสารทางเดียว: ตอนหาดใหญ่ 68 รัฐส่ง Cell Broadcast หลายรอบ แต่หลายคนไม่รู้หรือรู้ช้า มีคำขอความช่วยเหลือซ้ำกันเยอะ และผู้สูงอายุที่ไม่มีมือถือไม่โผล่บนแผนที่ขอความช่วยเหลือเลย ผลคือตาย 162 คน และหลายพื้นที่การช่วยเหลือยังเข้าไปไม่ถึง
ไทยพีบีเอสเตือนเรื่องช่วงเวลาทอง 48 ชม. ของกลุ่มเปราะบางที่ติดค้างในน้ำ
ผู้สูงอายุราว 1 ใน 3 ไม่ใช้อินเทอร์เน็ต (สสช.)
งานวิจัยพบว่าคำเตือนที่บอกผลกระทบพร้อมสิ่งที่ต้องทำ ทำให้คนตั้งใจป้องกันตัวมากกว่า (Weyrich 2018)
ยังขาดเสียงจากผู้ใช้จริง ต้องไปคุยกับคนจริงก่อน

5) เดโม 60 วินาที — (ดูหัวข้อ "เดโม 60 วินาที" ด้านบน คัดลอกคำต่อคำแล้ว)

Cell Broadcast และหอกระจายข่าวส่งได้ทางเดียว
ญี่ปุ่นมีวิทยุรับข่าวภัยในบ้าน ระบบดิจิทัลปี 2001 รองรับการส่งข้อความกลับไปหาราชการได้ แต่ปี 2017 ถูกเสนอให้ตัดฟังก์ชันสองทางออกเพราะเครื่องแพง

Traffy Fondue และแอปตอนหาดใหญ่ต้องใช้เน็ตและสมาร์ตโฟน

### สรุปที่ล็อกแล้ว (ต้นฉบับ)
ชื่อไอเดีย: ปุ่มเรียกเรือ — กล่องคุยสองทางสำหรับบ้านน้ำท่วม

ปัญหาที่ล็อกไว้ (B3): ในน้ำท่วม การสื่อสารกับบ้านเปราะบางเป็นทางเดียว — คนเตือนไม่รู้ว่าใครไม่ได้ยิน คนขอความช่วยเหลือไม่รู้ว่ามีใครได้ยิน
ผู้ใช้หลัก + ช่วงเวลา: ผู้สูงอายุ/ผู้ติดเตียงในพื้นที่น้ำท่วม (เน้นไม่มีสมาร์ตโฟน) — (ก) 12–48 ชม.ก่อนน้ำเข้าบ้าน (ข) ตอนติดอยู่ ไฟดับ เสามือถือล่ม

ต้นเหตุ: คำเตือน/คำขอวิ่งทางเดียว ไม่มีการยืนยันกลับ + ช่องทางพึ่งมือถือ/เน็ตที่ล่มตอนน้ำท่วม
ตัวงัด (lever): ปิดวงจรทั้งสองทาง — รู้ว่าใครไม่ได้ยิน (ไปเคาะก่อน) / บอกคนขอว่ามีคนได้ยินแล้ว / ขอแทนคนที่กดไม่ได้

 ใช้กล่องจริงถ้ามี ไม่มีใช้เว็บ 3D บนแท็บเล็ต (ติดป้าย "จำลอง") · ผลทั้งหมด "รอผลทดสอบ 25 ต.ค."
สิ่งที่มีอยู่แล้ว / ข้อดี / ข้อสงสัย / เราต่าง / เราเอามาใช้:
 - Cell Broadcast, หอกระจายข่าว: ถึงคนเยอะ / ทางเดียว / เรามีการยืนยันกลับ
 - วิทยุรับข่าวภัยในบ้านญี่ปุ่น: ในบ้าน ใช้ได้ตอนไฟดับ / เคยมีสองทางแต่ถูกเสนอตัดเพราะแพง / เราทำสองทางราคาถูกด้วย LoRa / เอามา: เสียงดังสุดเมื่อฉุกเฉิน + ไฟติดตอนไฟดับ
 - FMAS: LoRa SOS + แผนที่ / ไม่บอกว่าคนขอได้อะไรกลับ (ห้ามพูดว่า "FMAS ตอบกลับไม่ได้") / เราต่างที่ไฟสถานะ + 1 บ้าน 1 คำขอ + ขอแทน / เอามา: แผนที่สด
 - Traffy/แอปหาดใหญ่: คนใช้เยอะ / ต้องมีเน็ต+สมาร์ตโฟน, ข้อมูลกระจาย / เราไม่ต้องใช้ทั้งสองอย่าง
ความเสี่ยง + แผนสำรอง:
 - ระยะ LoRa ในเมืองน้ำท่วมยังไม่ได้ทดสอบ → ตั้งตัวรับสูง, ทดสอบระยะ 24 ต.ค.ถ้ามีบอร์ด
 - คนลืมกดเขียว → ออกแบบให้ "เงียบ = ได้รับความสนใจมากขึ้น" ไม่ใช่น้อยลง
 - ขออัตโนมัติผิด → อสม.ยืนยันก่อนส่งเรือ
 - ใครเป็นคนส่งคำเตือน → อปท./ปภ. (PoC จำลองหน้าจอผู้ส่ง)
 - งานบานเกิน 1.5 วัน → PoC = กล่อง 2 + ตัวรับ 1 + แดชบอร์ด เท่านั้น
แผนพัฒนา (ใส่ในเอกสาร): ปุ่มแยกประเภทคำขอ · บ้านข้างเคียงส่งต่อสัญญาณ (แนว Meshtastic) · ความสูงน้ำรายบ้านอัตโนมัติจาก ThaiWater · หมุดเฝ้าคันกั้นน้ำ
ใครจ่าย (Business): อปท./ปภ. ซื้อชุดให้บ้านเปราะบาง + ค่าดูแลรายปี · CSR ค่ายมือถือ (ล่มตอนน้ำท่วม) · แพ็กเกจ "1 บริษัท 1 ชุมชน"
ไอเดียสำรอง: เส้นน้ำพรุ่งนี้ (ข้อ 1 เดิม — ทดสอบได้แม้ไม่มีบอร์ด)
