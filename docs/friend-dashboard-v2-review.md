# ความเห็นต่อแดชบอร์ด v2 ของเพื่อน (FloodLink-Dashboard-v2-20261109-Ready.zip) — 11 พ.ย. 2569

ตรวจโดยอ่านโค้ดใน `public/` (serial.js, protocol.js, session.js, app.js บางส่วน) + เปิดหน้าเว็บในโหมดทดลอง · ไม่ได้รัน runtime/node.exe และ serve.mjs ของชุดนี้ด้วยตัวเอง · **ภายหลังผู้ใช้ทดสอบกับตัวรับจริงแล้ว ดูหัวข้อ "ทดสอบกับตัวรับจริง" ท้ายไฟล์**

## สรุป: ใช้ได้ ควรเอาไปทดสอบกับตัวรับจริงต่อ
เพื่อนแก้ตามเอกสารของเราครบทุกข้อใน `friend-dashboard-compat.md` และทำตาม `dashboard-ux-brief.md` ละเอียดกว่าที่คาด

## ที่ดี
- **พูดภาษาเดียวกับตัวรับเราแล้ว:** รับ `snap` v2 / `hb` / `res` ส่ง `{"cmd","rid"}` ครบ 7 คำสั่ง · ส่ง `hello` ตอนเปิดพอร์ต · ข้ามบรรทัดที่ไม่ใช่ JSON (boot log) · บรรทัดยาวถึง 64 KB · ไม่เช็กค่าวิทยุ SF7/10 dBm อีกแล้ว
- **ทำตามกติกาขาดการเชื่อมต่อ:** ไม่ได้ `hb` 3 รอบ (ใช้ `cfg.link_hb_s`) → ข้อมูลจาง ล็อกปุ่ม · `rev` ไม่ตรง → ขอ `hello` · `now` ถอยหลัง (ตัวรับรีสตาร์ต) → ทิ้งข้อมูลเก่า ขอใหม่ · ไม่ได้ `res` ใน 5 วิ → ข้อความข้างปุ่ม · แปล `err` ทุกตัวเป็นภาษาคน
- **ไม่เปลี่ยนสถานะบนจอเอง** รอ `snap` ยืนยัน · กดปุ่มคำสั่ง 2 ครั้งเพื่อยืนยัน แล้วล็อกบ้านนั้นจนได้ผล
- ลำดับคิว (ขอแทน → ติดเตียง → ตามเวลา → รับแล้ว) · ป้ายซ้อนครบตามบรีฟ · `state` แปลก ๆ ขึ้น "ไม่ทราบ" สีเทา ตัวเลขหาย "—"
- **ไม่โหลดอะไรจากเน็ต** (ฟอนต์ Anuphan + Leaflet อยู่ในชุด) · มีโหมดตัวอักษรใหญ่สำหรับโปรเจกเตอร์ · โหมดทดลองมีฉาก "เหตุเยอะ 60 บ้าน" และกล่องเสมือน
- ตอนต่อกลับอัตโนมัติ ถ้ามีพอร์ตที่เคยอนุญาตมากกว่า 1 จะไม่เดา (กันเลือกกล่องบ้านแทนตัวรับ) — คิดมาดี
- เอกสารพูดตรง: "ผ่านทดสอบด้วยตัวรับจำลอง ยังไม่ได้ทดสอบกับบอร์ดจริง" และชี้ว่าเอกสารเราเองเขียนชื่อวิทยุไม่ตรงกัน (SX1262 ใน data-contract vs SX1276 ในบรีฟ) — ถูกต้อง ต้องแก้ฝั่งเรา

## ที่ต้องคุยกัน / ยังไม่แน่
1. **หน้าตาไม่ตรง `design-direction.md`** ที่เลือกไว้ ("แบบแปลนวิศวกร" ขาว-เทา เส้นบาง) ของเพื่อนเป็นแบบแอปสมัยใหม่ (แถบข้างน้ำเงินเข้ม การ์ดใหญ่ ไอคอนสี) ดูดีและอ่านง่าย แต่เป็นคนละทิศกับหน้าอื่นของเรา (exploded, wiring) — เจ้าของโปรเจกต์ต้องเลือกว่าจะใช้ทิศไหน
2. **ยังไม่เคยต่อตัวรับจริง** ต้องลอง B3.2 ซ้ำกับแดชบอร์ดนี้: เชื่อม COM5 → ต้องเห็นบ้านทดลอง 1 → กดแดง → รับเรื่อง → ช่วยเสร็จ → ถอดสาย
3. **ต้องมีเซิร์ฟเวอร์ของเขา** (`Start-Dashboard.cmd` = node.exe 92 MB + serve.mjs) สำหรับทะเบียนพิกัดบ้านและแผนที่ประเทศไทยออฟไลน์ (ไฟล์แผนที่ 897 MB) → ขึ้น GitHub Pages แบบ static ไม่ได้ ใช้ได้เฉพาะบนโน้ตบุ๊กสถานี ถ้าเปิดแบบไฟล์ธรรมดา แผนที่จะเป็นผังชุมชน x,y ชั่วคราวแทน (ยังใช้งานได้)
4. ชุดมี 950 MB ส่วนใหญ่คือแผนที่ ถ้าจะเก็บใน repo ต้องแยกแผนที่ออก
