## งาน
1. **director → `exploded/storyboard.md`** เขียนใหม่ สั้นกว่าเดิม เรื่องที่ต้องเล่า:
   1. ปัญหา: การสื่อสารตอนน้ำท่วมเป็นทางเดียว — คนเตือนไม่รู้ว่าใครไม่ได้ยิน คนขอไม่รู้ว่ามีใครได้ยิน (ตัวเลขจาก "กติกาตัวเลข" เท่านั้น + แหล่งที่มาใต้ทุกตัว)
   2. กล่องประกอบเสร็จ + hook "ก่อนน้ำมาถามว่า ได้ยินไหม / พอน้ำมาแล้วตอบว่า ได้ยินแล้ว กำลังไป"
   3. แยกชิ้นตาม parts.md รุ่น 2 แต่ละชิ้นบอกว่าช่วยหน้าที่ไหน: เตือน / ขอช่วย / ขอแทน + ราคาต่อชิ้นจาก parts.md (รวม ≈ 545–645 บาท ติดว่า "ประมาณการ")
   3b. **Wiring Diagram (ผู้ใช้ขอ):** เลื่อนต่อแล้วกล้องเข้าไปในกล่อง ชิ้นส่วนจางลง เห็นสายไฟวิ่งระหว่างชิ้นทีละกลุ่ม (ไฟเลี้ยง → วิทยุ SPI → ปุ่ม → ไฟสถานะ → เสียง → ไฟกะพริบ) พร้อมป้ายขา เช่น `GPIO3 → ปุ่มแดง` ทุกเส้นต้องตรง `docs/wiring.md`
   4. ไฟ 4 สีมีความหมายเดียว (ส้ม เขียว แดง เหลือง) + เสียงพูด
   5. 3 หน้าที่ของกล่อง (เตือน → บ้านเงียบ / ขอช่วย / ขอแทนบ้านติดเตียง) เล่าด้วยเรื่องยายสมศรี (กำกับ "เรื่องสมมติ")
   6. ต่างจากของเดิมอย่างไร: Cell Broadcast, วิทยุญี่ปุ่น, FMAS, Traffy — ใช้ถ้อยคำตาม idea.md เท่านั้น (FMAS: "ไม่ได้บอกว่าคนขอได้อะไรกลับ")
   7. "รอผลทดสอบ 25 ต.ค." (ระยะส่งสัญญาณ + ผลทดสอบผู้ใช้)
   8. ฉากสุดท้าย: ลองใช้กล่องเสมือนจริง (ข้อ 3) + ปุ่มไป `../dashboard/`
2. **modeler → `exploded/parts.js`** สร้างชิ้นใหม่ให้ตรง parts.md ทุก id (ยกเว้น `radio-proto`) **ผู้ใช้ขอให้เหมือนของจริง:** ทำตามคอลัมน์ "หน้าตาจริง" และขนาดในตาราง ค้นภาพ/สเปกจริงเมื่อไม่แน่ใจ (เช่น ขนาด Wio-SX1262 จากหน้า Seeed) แล้วเขียนแหล่งไว้ในคอมเมนต์
   - รายละเอียดที่ต้องเห็น: USB-C และชิปบน Super Mini, รูระยะ 2.54 มม. บนแผ่นไข่ปลา, ฝาโลหะของโมดูลวิทยุ, ไฟ 8 ชิ้นแยกกันต่อสายสั้น 3 เส้น, รางถ่านมีฝา+สวิตช์ และถ่าน 3 ก้อน, ลำโพงขอบโลหะ, ทรานซิสเตอร์ TO-92, LED บนแผ่นดาว, ไมโครสวิตช์ใต้ปุ่ม, ลวดเสา 81 มม.
   - ไฟ 8 ดวงต้องเปลี่ยนสีทีละดวงได้ (ส้ม/เขียว/แดง/เหลือง)
   - ใส่จุดยึดสาย (ตำแหน่งขาของแต่ละชิ้น) ให้ animator ลากสายตาม wiring.md ได้ เช่น `pins: { GPIO3: [x,y,z] }`
   - ส่งให้ checker ตรวจขนาด/การวางเทียบหัวข้อ "เช็กแล้วว่าใส่กันได้" ใน parts.md ถ้าชนกันให้รายงาน ห้ามย่อขนาดชิ้นเอง
3. **animator → `exploded/index.html` `scroll.js` `style.css`** ฉากตาม storyboard, **ฉาก Wiring Diagram** (สายเป็นเส้น/ท่อบาง ๆ ใน 3D สีตาม design-direction.md มีคำอธิบายสี ค่อย ๆ วาดทีละกลุ่มตามการเลื่อน มีปุ่ม "ดูผังแบบแบน" สลับเป็นผัง 2D จากข้อมูลชุดเดียวกัน — บนมือถือใช้ผัง 2D เป็นหลักถ้า 3D แน่นจนอ่านไม่ออก) และ **ฉากลองใช้กล่องเสมือนจริง** (ป้าย "จำลอง — ลองกดดูว่ากล่องทำงานอย่างไร"):
   - หมุนกล่องได้ (ลากเมาส์/นิ้ว) ปุ่ม "หันหน้าตรง" ล้อเมาส์ยังเลื่อนหน้า เลื่อนขึ้นแล้วออกจากโหมด — ใช้โค้ดเดิมจากรุ่น 1
   - **3 สถานการณ์ให้เลือก** (แท็บหรือปุ่มเลือก ข้างกล่องมีจอเล็ก "จอทีมช่วยเหลือ (จำลอง)"):
     - **เตือน:** กด "ส่งคำเตือน (จำลอง)" บนจอเล็ก → วงแหวนส้มกะพริบ + เสียงเตือนตาม idea.md → กดปุ่มเขียวบนโมเดล → ไฟเขียว + "ขอบคุณ ทีมรู้แล้วว่าบ้านนี้ได้ยิน" และจอเล็กนับเป็น "ได้ยินแล้ว" · กดเขียวสั้นอีกครั้ง = ฟังข้อความล่าสุดซ้ำ · ถ้าไม่กด → เดินเวลาเร่ง → บ้านขึ้นรายการ "บ้านที่ยังเงียบ" บนจอเล็ก
     - **ขอช่วย:** กดแดงค้างครบ 2 วิ (ปุ่มยุบ + วงความคืบหน้า ปล่อยก่อน = "กดค้างให้ครบ 2 วินาที") → แดง + คำพูด → จอเล็ก "รับเรื่อง" → เหลือง + "ทีมรับเรื่องแล้ว กำลังมา" → "ช่วยเสร็จ" → เขียว · กดแดงซ้ำ = ไม่เพิ่มคำขอ · กดเขียวค้าง 2 วิ = ปลอดภัย ยกเลิกคำขอ ("ยกเลิกคำขอแล้ว ทีมรู้ว่าบ้านนี้ปลอดภัย")
     - **ขอแทน (บ้านติดเตียง):** แถบเลื่อนให้น้ำขึ้นในบ้าน → น้ำถึงปลายสายวัด 2 เส้นที่แขวนไว้ 50 ซม. (เห็นในฉาก) + ไม่มีใครตอบ (นับเวลาเร่ง) → กล่องขอเอง ไฟแดง + คำพูด → จอเล็กขึ้นลำดับแรกพร้อม "อสม. ยืนยัน"
   - คำพูดทุกคำจากตาราง "คำพูดของกล่อง" ใน idea.md ห้ามแต่งใหม่ แสดงเป็นลูกโป่งคำพูดข้างกล่อง (รวม "ยังส่งไม่ถึง กำลังลองใหม่" ให้กดลองได้ด้วยปุ่ม "จำลองส่งไม่ถึง" และคำเตือนพูดซ้ำทุก 10 นาที = แสดงเป็นเวลาเร่ง)
   - **เสียง:** ใช้ `speechSynthesis` เสียงไทย (th-TH) ถ้าเครื่องมี ไม่มีก็ใช้เสียงบี๊บ Web Audio + ลูกโป่งคำพูด · มีปุ่มปิดเสียง · ไม่โหลดอะไรจากเน็ต
   - ไฟดูเหมือนจริง (ติดทีละดวง / แสงฟุ้ง) ไม่ใช้เอฟเฟกต์หนักบนมือถือ
   - ตัวเลขออกแบบเอง (2 วิ, 6 ชม., 50 ซม., 2 ชม.) ติด "ค่าออกแบบ จะปรับหลังทดสอบ" + ป้าย "เดโมเร่งเวลา"
   - ปุ่มบนจอขนาดใหญ่สำรองสำหรับจอสัมผัส ("กดค้างปุ่มแดง", "กดปุ่มเขียว") · มือถือกดค้างแล้วหน้าไม่เลื่อน/ไม่ขึ้นเมนู
   - `?record=1` เล่นเองครบ 3 สถานการณ์ต่อกัน · ทางสำรอง 2D (`?still=1` / ลดการเคลื่อนไหว) กดได้ลำดับเดียวกัน
   - ปุ่ม "ลองกดของจริง" ของรุ่น 1 เอาออก (รอบนี้ไม่มีอุปกรณ์จริง)
4. **checker → `exploded/CHECK.md`** (เขียนทับ เก็บเฉพาะประเด็นเปิด ≤ 80 บรรทัด ต่อของเดิมเข้า `_archive/reviews/` ด้วย shell ก่อน)

   - ฉาก Wiring: ทุกเส้นบนจอตรงกับตารางเส้นสายใน wiring.md ทั้งจำนวนและปลายทาง (เทียบด้วยโค้ด ไม่ใช่ด้วยตา)
